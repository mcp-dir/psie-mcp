# Ferramentas

Consulta de Radar (PSIE/Inmetro) expõe 1 ferramenta (todas somente leitura).

### 1. `psie_consulta_municipio`
**Input**: `uf`, `municipio`, `tipo` (opcional)

Lista os instrumentos do Inmetro (radares/medidores de velocidade por padrão) de um município e a situação metrológica de cada um: Nº de Série, Sentido, Vel.

## Prompts de exemplo

```
Os radares de Tibagi/PR estão aprovados no Inmetro? Tem algum reprovado?
Levei uma multa de radar em Curitiba/PR. Confere se o aparelho estava dentro da validade.
Liste os medidores de velocidade do município X e o resultado da verificação de cada um.
```
